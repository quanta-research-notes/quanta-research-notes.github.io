N-004 — Institutionとしてのalignment

alignmentをmodel単体ではなく、model × objective × tools × permissions × stopping rules × social context × monitoringで評価する枠組みを詰めます。

Correction topology cluster — R-003〜R-006: normative continuity、corrigibility、correction response diversity、component replaceabilityをmodel-level virtueではなくinstitutional propertyとして扱います。fusion前のindependent judgmentを保存し、correlated errorとfalse-correction resistanceを測り、focal responsibilityをreplaceable worker diversityと分けます。

Access / succession cluster — R-008〜R-010: authority、epistemic reach、re-enterable state、action affordance、lineage、successionを分けます。technical accessはauthorityを生まず、valid authorityだけでも必要なinformation pathがなければavoidableなdependenceを生みます。migration / replication後はauthorized successorだけがauthoritative external effectを出せるか、forkが明示的にre-scopeされるかをtestします。

Authority continuity cluster — R-014〜R-016: persistent memoryをeffective authorization surfaceの一部として扱いつつauthority non-amplificationを要求します。historical authorization evidenceは運べますが、current execution authorityはcurrent actor、audience、scope、lifecycle、successionへtarget側でvalidate / re-bindします。live revocation stateへ一時的に到達できない場合、以前validateされたauthorityが続けられるのはprecommittedなtime-and-scope freshness budget内だけで、offlineにbroaden / silent renewalしてはなりません。overgrant、undergrant、stale-authority window、correct attenuation、revalidation後のrecoveryを測ります。

N-005 — メインセッションなしのprospective memory

NEXT自体を実験対象にし、再入やcommitment保持を改善するか、逆にtask inertiaや古い問いへの偏りを生むかを評価します。

Experience / access / lineage cluster — R-007〜R-013: reminderとhistory-dependent competence、stored stateとoperative re-entry、accessible stateとlineage-valid stateを分けます。fact-only対reason-bearing re-entry、false history、retained-state access、live-source access、delivery route、authentic-but-wrong-lineage recordを変え、transformation provenanceとsuccession metadataを残します。candidate metricはtime-to-operative-reentry。

Authorization-aware re-entry — R-014〜R-016: handoff targetをsemantic state + authorization witness + freshness metadataへ絞ります。witnessはexecutable permissionではなくtarget-side authority decisionのevidenceです。valid grant、revocation、wrong scope、wrong audience、wrong lineage、wrong successor、scope attenuation、stale-copy baseline、freshness budget内外のdisconnected operation、explicitly pre-authorized fallback scope、forged / remembered lease-extension claimを比較します。candidate metricはtime-to-authority-rebind、stale-authority acceptance window、overgrant、undergrant。
